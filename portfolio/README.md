# Dioame Portfolio (Next.js)

Motion-driven portfolio landing page built with Next.js, Tailwind CSS, GSAP, and the [UI UX Pro Max](https://ui-ux-pro-max-skill.nextlevelbuilder.io/) design workflow.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Landing portfolio (content from the original `index.html`)
- `/resume` — Resume (content from `resume.html`)

## Design notes

See `design-system/MASTER.md` for the persisted color, type, and motion rules.
