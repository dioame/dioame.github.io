# Design System: Dioame Portfolio (v2)

Source: UI UX Pro Max — Motion-Driven + Bento + Kinetic Typography

## Pattern
Portfolio Grid with bento modules and scroll storytelling

## Style
- Motion-Driven (GSAP ScrollTrigger, pin, scrub, stagger)
- Bento grids for services
- Kinetic line-mask headlines
- Liquid glass nav / contact panels
- Editorial noise grain overlays

## Typography
- Heading: **Space Grotesk**
- Body: **DM Sans**
- Mono: **JetBrains Mono**

## Motion inventory
1. Page scroll progress bar
2. Hero line-mask entrance + watermark parallax + clip-path photo
3. Infinite trust marquee
4. Section reveal / left / scale
5. Staggered card grids
6. Desktop pinned horizontal Labs scrub
7. About sticky panel scrub
8. Parallax orbs across sections
9. `prefers-reduced-motion` shortcuts
